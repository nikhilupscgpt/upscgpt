The answer sheet that becomes the spark.

Every Prelims aspirant knows the OMR sheet: four bubbles, one pencil mark. In this loader the four options get marked one by one, then pull together into the four points of the ✦ in the UPSCGPT logo. It loops while the page fetches, so the wait shows the habit the site is built around.

The caption changes once per loop, so a long wait reads as progress instead of a stuck spinner.

Why this one

Generic spinners say "wait". This one is made only of things a UPSC aspirant sees every day: the a/b/c/d bubble, the question number, the pencil fill. It ends on the logo's own ✦, so the brand mark is the payoff of every loop.

Building it for real

The whole animation is one function, render(t), that draws a frame from a time in milliseconds. That ports straight to a React component with requestAnimationFrame, or to a Remotion composition using useCurrentFrame() if you want it as a video for reels. Under reduced motion it shows a still ✦.
